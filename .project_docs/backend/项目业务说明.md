## 1. 核心业务流程

### 销售订单全流程

```
创建订单(DRAFT) → 确认订单(CONFIRMED) → 发货(DELIVERED) → 结算(SETTLED) → 完成(COMPLETED)
                                     ↘ 取消(CANCELLED)
```

**关键规则**：
- 订单号格式：`SO{日期}{4位随机数}`（如 SO202605050001）
- 税率：从商品/配置读取，不硬编码
- 订单项不能为空
- 状态流转必须按合法路径进行

### 采购单全流程

```
创建采购单(DRAFT) → 确认(CONFIRMED) → 到货入库 → 结算 → 完成
                                ↘ 取消(CANCELLED)
```

**关键规则**：
- 采购单可从销售订单推送生成
- 入库操作需检查库存权限

### 库存管理流程

```
入库 → 库存增加 → 出库 → 库存减少
         ↓
      库存盘点/调整
```

**关键规则**：
- 出入库操作需 `stock.edit` 权限
- 所有操作记录到 stock_batches（批次表）

### 应收款流程

```
销售订单完成 → 生成应收款记录 → 收款确认 → 标记已收
```

## 2. 业务注意事项

### 认证与权限

- admin 角色拥有所有权限
- JWT Token 存储在 localStorage，包含 `token`、`user`、`token_expires_at`
- 退出登录需清除所有认证数据
- WebSocket 连接跳过认证（路径以 `/ws/` 开头）

### 数据一致性

- MongoDB 集合命名统一使用小写下划线（如 `sales_orders`、`product_categories`）
- `BaseService.update` 支持以 `$` 开头的 MongoDB 操作符透传（如 `$push`、`$pull`）
- 嵌套对象验证需通过 `fields` 键支持递归校验

### 业务约束

### 供应商管理规则

- 供应商名称全局唯一，创建/更新时校验
- 删除供应商前检查是否有采购单关联，有则禁止删除
- 支持按名称关键词搜索和按激活状态筛选
- 供货品牌列表校验：品牌ID必填，折扣率必须在0-1之间

### 业务约束
| 约束 | 说明 |
|------|------|
| 供应商唯一性 | 供应商名称不允许重复，创建和更新时校验 |
| 供应商删除保护 | 供应商下存在采购单时禁止删除 |
| 品牌删除保护 | 品牌下存在关联商品时禁止删除 |
| 分类删除保护 | 分类下存在子分类或关联商品时禁止删除 |
| 客户销售人 | 新建/编辑客户时自动设置为当前鉴权人 |
| 商品规格 | 一个商品可有多个规格，展示时需垂直展开 |
| 商品编号 | 系统自动生成，格式 `PROD{日期}{6位随机数}`，全局唯一 |
| 规格编号 | 系统自动生成，格式 `SPEC{日期}{6位随机数}`，全局唯一 |
| 品牌唯一性 | 品牌名称不允许重复，创建和更新时校验 |
| 分类唯一性 | 分类名称不允许重复，创建和更新时校验 |
| 商品-品牌/分类冗余 | 创建和更新商品时，系统自动根据 brand_id / category_id 填充 brand_name / category_name 到商品记录中 |
| 订单状态 | 不允许非法状态转换（需状态机校验） |
| 库存操作 | 出入库需权限检查（`stock.edit`） |

### 商品/品牌/分类业务规则

**品牌管理**：
- 品牌名称全局唯一，创建/更新时校验
- 删除品牌前检查是否有关联商品，有则禁止删除
- 支持按名称和描述模糊搜索

**分类管理**：
- 多级树形结构（数据层级限制5层以下），通过 `parent_id` 关联父级
- 删除分类前检查：(1) 是否有子分类 (2) 是否有关联商品，有则禁止删除
- `GET /categories/` 返回完整分类树，递归构建 `children` 字段

**商品管理**：
- 创建商品时需提供有效的 `brand_id` 和 `category_id`
- 创建和更新时自动填充冗余字段 `brand_name` / `category_name`
- 删除商品时自动删除所有关联规格
- 商品详情接口返回完整规格列表

**规格管理**：
- 规格归属于商品（通过 `product_id` 关联）
- 支持按规格编号搜索
- 规格编号全局唯一，由系统自动生成

## 4. 数据库集合说明

### 主要集合

| 集合名 | 说明 |
|--------|------|
| users | 用户信息 |
| customers | 客户信息 |
| customer_discounts | 客户折扣规则 |
| products | 商品信息 |
| product_specs | 商品规格 |
| product_categories | 商品分类 |
| product_brands | 品牌信息 |
| suppliers | 供应商信息 |
| sales_orders | 销售订单 |
| purchase_orders | 采购单 |
| inventory_stocks | 库存信息 |
| inventory_inbound_batches | 入库批次记录 |
| inventory_outbound_batches | 出库批次记录 |
| inventory_warehouses | 仓库信息 |
| accounts_receivable | 应收款 |
| permissions | 权限定义 |
| roles | 角色定义 |

### 命名规范

- 集合名使用小写下划线
- 禁止混合使用驼峰和下划线（如 `salesOrders` 应为 `sales_orders`）
