## API 服务

所有后端接口调用统一在 `services/api.ts` 中定义，按模块导出：

| API 对象 | 说明 |
|---------|------|
| `xxxApi` | 各模块 API 调用方法 |

**标准方法**：
- `list(params)` — 列表查询
- `getById(id)` — 详情查询
- `create(data)` — 创建
- `update(id, data)` — 更新
- `delete(id)` — 删除
