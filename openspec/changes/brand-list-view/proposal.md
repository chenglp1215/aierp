## Why

当前品牌管理页面使用卡片网格布局展示品牌信息，存在以下问题：
1. **信息展示不全**：卡片形式空间有限，无法完整展示品牌的所有字段（如采购人员、描述等被截断）
2. **风格不一致**：分类管理和商品管理都采用表格列表形式，品牌管理使用卡片形式与其他模块风格不统一
3. **操作效率低**：卡片布局下批量操作和快速浏览对比不如表格直观

## What Changes

- 将品牌管理从卡片网格布局改为表格列表布局
- 使用 vxe-table 组件展示品牌数据（与商品管理保持一致）
- 表格列包含：品牌名称、Logo、描述、采购人员、状态、商品数量、更新时间、操作
- 保留现有的筛选、搜索、分页功能
- 保留现有的新建/编辑/删除弹窗

## Capabilities

### New Capabilities
无新增能力，仅前端展示形式调整。

### Modified Capabilities
- `brand-management-ui`: 品牌管理前端展示形式从卡片改为表格列表

## Impact

- **前端**：`web/src/components/workspace/BrandWorkspace.vue` 需要重构
- **后端**：无变更，现有 API 已支持所需数据
- **API**：无变更
