## Context

当前品牌管理页面（BrandWorkspace.vue）使用卡片网格布局展示品牌信息，与分类管理（树形表格）和商品管理（vxe-table 表格）的展示风格不一致。需要将品牌管理改为表格列表形式，保持与其他模块的风格统一。

**技术约束：**
- 使用 vxe-table 4 组件（与商品管理一致）
- 保持 Vue 3 Composition API + `<script setup lang="ts">` 风格
- 现有 API 无需变更，后端数据已支持所需字段

## Goals / Non-Goals

**Goals:**
- 将品牌展示从卡片网格改为 vxe-table 表格列表
- 完整展示品牌所有字段信息
- 保持与商品管理一致的交互风格
- 保留现有筛选、搜索、分页、弹窗功能

**Non-Goals:**
- 不修改后端 API
- 不新增品牌字段
- 不改变品牌管理的业务逻辑

## Decisions

### 1. 使用 vxe-table 组件

**选择 vxe-table 而非原生表格的原因：**
- 与商品管理保持一致
- 内置分页、排序、列宽调整等功能
- 支持固定列、自定义单元格渲染

### 2. 表格列设计

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| Logo | logo_url | 80px | 图片缩略图，无图时显示首字母 |
| 品牌名称 | name | 150px | 主字段 |
| 描述 | description | 自适应 | 完整展示，超长截断 |
| 采购人员 | purchaser_name | 100px | 关联用户名 |
| 状态 | is_active | 80px | 启用/停用标签 |
| 商品数量 | product_count | 80px | 关联商品统计 |
| 更新时间 | updated_at | 140px | 格式化日期 |
| 操作 | - | 180px | 编辑、启用/停用、删除按钮 |

### 3. 保留现有弹窗

新建/编辑品牌弹窗保持不变，仅修改列表展示部分。

## Risks / Trade-offs

**无重大风险**，仅前端展示层调整，不涉及数据层变更。
