构建错误修复测试

1. 错误信息

构建错误：

src/components/workspace/CustomerDiscountWorkspace.vue:192:7 - error TS6133: 'formatDate' is declared but its value is never read. 192 const formatDate = (dateStr: string) => {

错误原因：在移除创建时间列后，formatDate函数不再被使用，但仍然声明了。

2. 修复方案

修复前：

const formatDate = (dateStr: string) => { if (!dateStr) return '-' const date = new Date(dateStr) return date.toLocaleString('zh-CN', { year: 'numeric', month: '2-digit', day: '2-digit', hour: '2-digit', minute: '2-digit' }) }

修复后：删除整个formatDate函数

原因分析：

  • 在之前的表格布局调整中，我们移除了"创建时间"列
  • formatDate函数原本用于格式化创建时间列的显示
  • 移除列后，函数不再被调用，导致TypeScript错误
