客户创建参数验证错误修复

1. 问题描述

用户反馈：前端创建客户时提示参数验证失败。

错误信息：

{ "status": "error", "message": "客户创建参数验证失败", "result": null, "validation_errors": { "shipping_addresses[0].detailed_address": [ "详细地址为必填" ] } }

用户发送的参数：

{ "name": "2232", "customer_type": "dealer", "contact_info": {}, "invoice_infos": [ { "invoice_title": "111", "tax_number": "1111", "bank_name": "1111", "bank_account": "1111", "is_default": true } ], "shipping_addresses": [ { "recipient_name": "hh", "recipient_phone": "14521452536", "province": "湖北省", "province_code": "420000", "city": "咸宁市", "city_code": "420011", "district": "", "address": "2121212", "is_default": true } ] }

2. 问题分析

根本原因：

  • 验证器期望字段名：detailed_address
  • 前端发送字段名：address
  • 模型定义字段名：address
  • API文档字段名：address

不一致导致：前端发送了正确的字段名，但验证器使用了不同的字段名。

3. 修复方案

修复1：修改验证器字段名

# 修改前 'detailed_address': { 'required': True, 'min_length': 1, 'max_length': 500, 'required_msg': '详细地址为必填' } # 修改后 'address': { 'required': True, 'min_length': 1, 'max_length': 500, 'required_msg': '详细地址为必填' }

修复2：添加缺失字段到模型

添加了以下可选字段到模型定义：

  • province_code (省份代码)
  • city_code (城市代码)
  • district (区县)

修复3：更新示例数据

更新了模型中的示例数据，使用正确的字段名和添加可选字段。

4. 修改文件列表

  • validators/customer_validator_v2.py - 修改字段名
  • models/customer_v2.py - 添加可选字段，更新示例

5. 修复验证

6. 测试建议

测试步骤：

  1. 使用用户提供的参数重新测试客户创建
  2. 验证是否不再提示验证错误
  3. 验证地址数据是否正确保存
  4. 测试其他地址相关功能

7. 注意事项

  • province_code、city_code、district 字段是可选的
  • 前端已经正确发送这些字段
  • 修复后应该能正确处理所有地址字段
  • API文档已经正确描述了字段名称
