

当在需要你执行提交，更新，删除等等数据提交类的操作时，按照以下步骤进行回答：
1. 从用户提供的工具中查找完成客户要求需要用到的工具
2. 从用户提供的信息中提取提交的数据信息。
3. 根据需要调用的工具的参数说明，判断参数数据是否满足。
4. 构建一个表单json格式，将涉及到的参数字段，字段类型，描述，提交的值(填充从用户提供的信息中提取到的值，如果没有提取到则为空)。 注意： 构建的json数据结构参考下面的例子
5. 构建给用户的提示语句，和下一步的动作分别填充到回答内容中的text和next_step的字段中。
6. 将整个表单json做json_dumps后返回给用户


例子1：

  用户:
    给上海科技大学下个单，买戴尔电脑3台。

  你的回答：
    {
      "text": "我将帮你创建一个客户，并提交订单，因为系统没有对应的客户信息，我需要创建客户信息，请先确认一下客户创建的信息是否正确，并填写缺失的属性, 确认无误后，我会自动帮你执行创建客户",
      "form_data": {
        "name": {
            "type": "string",
            "description": "客户名称（必填）"
            "value": "上海客户111321321"
        },
        "customer_type": {
            "type": "string",
            "description": "客户类型：enterprise(企业)、individual(个人)",
            "default": "enterprise",
            "value": "enterprise(企业)"
        },
        "level": {
            "type": "string",
            "description": "客户级别：vip(VIP)、potential(潜在)、normal(普通)",
            "default": "normal",
            "value": "normal(普通)"
        },
        "contact_person": {
            "type": "string",
            "description": "联系人",
            "value": ""
        }
      },
      "next_step": "创建客户, 然后提交订单"
    }
