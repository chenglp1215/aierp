# 省份城市数据 API

<!-- 变更日期: 2026-05-12 -->

> 用于获取中国省份、城市、区县数据，无需登录即可访问

## 基础信息

- **基础路径**: `/api/v1/province-city`
- **认证方式**: 无需认证（公开接口）

---

## 接口列表

### 5.3.1 获取省份城市数据（合并接口）

### 接口信息

| 属性 | 值 |
|------|-----|
| **URL** | `GET /api/v1/province-city` |
| **Method** | GET |
| **认证** | 无需认证 |

### 功能说明

该接口一次性返回所有省份和城市的数据结构，适用于前端缓存。省市区数据为二级结构（省-市），直辖市保留到区县。

## 数据结构说明

### 直辖市（北京市、天津市、上海市、重庆市）

直辖市数据结构到区（县）级，例如：
```json
{
  "北京市": {
    "code": "110000",
    "cities": {
      "北京市": {
        "code": "110100",
        "districts": ["东城区", "西城区", "朝阳区", ...]
      }
    }
  }
}
```

### 普通省份

普通省份数据结构为省-市二级，市的 districts 为空数组：
```json
{
  "河北省": {
    "code": "130000",
    "cities": {
      "石家庄市": {"code": "130100", "districts": []},
      "唐山市": {"code": "130200", "districts": []}
    }
  }
}
```

---

## 错误响应

```json
{
  "status": "error",
  "message": "错误描述信息",
  "result": null
}
```
